### Accessibility Visual Elements

#### Focus Indicators
- Outline: 2px #3B82F6
- Border-radius: 4px
- Offset: 2px from element

#### High Contrast Elements
- Text on colored backgrounds: White
- Interactive elements: Minimum 4.5:1 contrast ratio
- Large text: Minimum 3:1 contrast ratio

### Responsive Visual Adaptations

#### Mobile Layout Changes
- Stacked elements instead of side-by-side
- Full-width buttons and inputs
- Larger touch targets (minimum 44px)
- Simplified navigation (hamburger menu)
- Bottom sheets for additional content

#### Tablet Layout Changes
- Hybrid layouts (some side-by-side, some stacked)
- Medium-sized touch targets
- Collapsible sidebars
- Adaptive grid systems

### Animation Visual Guidelines

#### Hover Effects
- Scale: 1.02 for cards
- Color transitions: 200ms ease-in-out
- Shadow changes: 200ms ease-in-out

#### Page Transitions
- Fade in: 300ms ease-in-out
- Slide animations: 400ms ease-in-out
- Staggered animations: 100ms delay between elements

#### Micro-interactions
- Button press: Scale 0.98
- Focus: Immediate outline appearance
- Loading: Smooth rotation/spin

### Color Usage Guidelines

#### Primary Colors
- #2563EB (Blue): Primary actions, links, active states
- #059669 (Green): Success states, accessibility features
- #F97316 (Orange): CTAs, important actions

#### Neutral Colors
- #1F2937 (Dark): Primary text, headings
- #6B7280 (Medium): Secondary text, inactive states
- #F3F4F6 (Light): Backgrounds, borders
- #FFFFFF (White): Primary backgrounds

#### Semantic Colors
- #10B981 (Success): Positive feedback
- #F59E0B (Warning): Caution states
- #EF4444 (Error): Error messages
- #3B82F6 (Info): Information states
